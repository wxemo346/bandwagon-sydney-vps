## 搬瓦工悉尼机房是什么水平：AUSYD_1 的线路和延迟

AUSYD_1 位于澳大利亚悉尼，是搬瓦工目前在澳大利亚的仅有机房，由 xTom 提供本地设施。它最大的卖点是线路：回程三网统一走联通 AS9929 这条精品线路，从中国香港接入悉尼。去程方向，电信走 163 直连，移动走 Telstra，联通走 AS9929。换句话说，不管你用哪家宽带，从国内连这台机器都不用绕美国，这在大洋洲节点里是相当少见的配置。

速度上，悉尼机房母鸡带宽官方口径为 2.5Gbps，用户端口为 1Gbps。已公开的测评显示，白天和晚高峰下载速度普遍能跑到数百 Mbps 的量级，日常建站和代理使用绰绰有余。测试 IP 是 103.57.167.1，想自己 ping 一下可以先从这里试。
